# 夕照草坪 3D

依照一張傍晚公園草坪的照片用 **three.js + 原生 JavaScript** 程序化重建的 3D 場景。
沒有使用 Blender，也沒有下載任何 3D 模型或貼圖：地形、樹木、人物、帳篷、球、眼球氣球、雲和貼圖全部在瀏覽器裡由程式碼生成。

## 執行

ES module 需要經由 HTTP 開啟（直接雙擊 `index.html` 會被瀏覽器擋下）：

```bash
cd park-3d
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

three.js（r160）透過 import map 從 jsDelivr CDN 載入，其餘都在本資料夾。
網址加 `?q=0.5` 可降低畫質（較少樹木、關閉草葉、2048 陰影貼圖），手機會自動使用低畫質。

## 操作

| 動作 | 效果 |
|---|---|
| 點擊草地 | 從相機丟出一顆足球（拋物線初速度解算）。附近的人會跑過去把球踢回給你 |
| 拖曳 / 滾輪 / 右鍵 | 旋轉、縮放、平移 |
| 回到照片視角 | 還原與照片相同的構圖 |
| 跟隨一個人 | 鏡頭跟著一位行人移動，可繞著他旋轉 |
| 吹一陣強風 | 陣風：樹葉、草、野餐墊邊緣、眼球氣球、球與飛盤都會受影響 |
| 風速 / 太陽仰角 | 即時調整風場與光線（低角度時光線偏暖、影子拉長） |

## 架構

| 檔案 | 內容 |
|---|---|
| `js/noise.js` | 可重現亂數、Simplex 噪聲、fBm |
| `js/terrain.js` | 高度場（縱向坡頂、左側野餐斜坡、步道整平、沙坑凹陷）、地表遮罩、程序化地面著色器（割草條紋、紅土落葉、沙） |
| `js/sky.js` | 天空穹頂著色器（漸層、層積雲、卷雲、太陽光暈）、兩層遠山 |
| `js/vegetation.js` | 闊葉樹（橢球樹冠 + 葉叢卡片 + 枝條）、木棉、大王椰子、灌木；風吹擺動的頂點著色器與對應的陰影材質 |
| `js/grass.js` | 跟著相機的草葉（17 萬片 instanced blades），在 GPU 讀高度圖與遮罩 |
| `js/physics.js` | 自製物理引擎（見下） |
| `js/people.js` | 程序化人體（InstancedMesh，12 種部件）、正向運動學骨架、程序化動畫、行為 AI |
| `js/props.js` | 野餐墊、帳篷、遮陽棚、推車、嬰兒車、冰桶、長椅、角錐、足球 / 大充氣球、飛盤、眼球氣球 |
| `js/world.js` | 依照片佈置整個場景 |
| `js/look.js` | 色調設定與調色後製（lift / gamma / gain、S 曲線、飽和度、分離色調、暗角）。數值是逐區比對照片色彩統計（天空、草坪亮部 / 暗部、左右樹冠、紅土）調出來的 |
| `js/main.js` | 渲染器、後製管線（HDR → ACES → 調色）、光照、陰影相機、操作與 UI |

### 物理模擬（`physics.js`，固定步長 1/120 秒）

- **剛體球**：重力、二次空氣阻力（相對於風速）、馬格努斯力、對高度場的碰撞（法線、恢復係數、撞擊摩擦）、草地滾動阻力、無打滑滾動角速度、休眠；與樹幹圓柱、靜態物件（球體 / 有向方盒）、人物膠囊體、其他球、眼球氣球的碰撞與衝量交換。
- **飛盤**：Hummel 簡化空氣動力模型（升力係數、阻力係數隨攻角變化），會飄、會落地滑行。
- **Verlet 繩索**：眼球氣球掛在樹枝上，受風阻與淨重力擺盪，被球打中會晃動；另有扭轉彈簧讓眼睛慢慢轉向觀看者。
- **Verlet 布料**：每張野餐墊 9×9 質點，結構 / 剪切 / 彎曲約束，地面碰撞與摩擦；坐著的人與物品壓住的質點固定，陣風會掀起邊角，球滾過去會壓到布。
- **風場**：方向 + 陣風噪聲 + 高度剖面，同時驅動物理與著色器（樹葉、草）。

### 人物

每個人由軀幹、骨盆、頭、頭髮 / 帽子、上臂、前臂、大腿、小腿、腳、裙子組成，每幀以正向運動學計算矩陣寫入 InstancedMesh（全部人物只用 12 個 draw call）。
動畫是程序化的：步態（走路與跑步依速度混合、步幅依實際位移推進避免腳底打滑）、五種坐姿、躺、蹲、坐長椅、踢球、丟飛盤、接飛盤、拍照、滑手機、揮手、被球打中時的反射動作，以及被強力擊中時跌倒再爬起。

行為：野餐（坐著聊天、吃東西、滑手機，偶爾起身走走再回來；小孩在附近跑）、草坪散步的家庭與情侶、步道行人、踢足球（選出追球者、傳給隊友）、小孩推大充氣球、丟飛盤、鬼抓人、站著聊天、坐長椅。
人群之間有分離力、避開樹幹 / 帳篷 / 別人的野餐墊，並以空間雜湊加速鄰近查詢。
